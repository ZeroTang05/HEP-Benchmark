# HEP 项目维护规范

本项目在本机执行论文预处理、任务生成、独立审核、解题、数值评分和科学评审。
运行框架使用官方 DeepSeek Harness。模型与资料服务通过 API 访问。

## 代码分工

- `recall/` 保存论文、官方数据和图文预处理缓存。
- `taskgen/core/` 保存通用匹配、批量执行和恢复逻辑。
- `taskgen/agents/` 保存 DeepSeek Harness 的进程适配。
- `taskgen/tasks/researchclawbench/` 保存 HEP 合同、Reviewer、Solver 和 Judge。
- 根目录的 `pyproject.toml` 与 `uv.lock` 管理 Python 环境。

## 科学与数据约束

记录真实来源、文件指纹、单位、分箱、误差和相关性假设。
公开题目、公开数据和先前文献必须足以支持独立解题。
目标论文、隐藏图像、参考数值和评分代码保持在私有区域。
科学审核和数值评分使用实际产物，保留明确证据与原始判断。

## 提示词维护

迭代提示词时，围绕任务目标检查整版提示词的结构和逻辑。把新要求融入相关步骤和判断标准，整理重复或矛盾的指令，避免逐条追加补丁。每一版提示词都应有连贯的内在逻辑和清晰的结构。

## 执行记录命名

运行目录和独立执行记录文件的名称以时间戳开头，统一使用 `YYYYMMDD-HHMMSS-任务名`，例如 `20261122-093000-ams02-taskgen`。这样按名称排序就是按执行时间排序。

## 开发与验证

Python 使用 3.10、类型注解和 pathlib。新增注释使用中文，术语保留英文。
配置结构与 `config/taskgen.yaml` 保持一致。秘密值只通过环境提供。
使用真实数据与真实服务进行单篇验证，批量运行前检查输入、输出和中间结果。
根据修改范围运行相关测试，重大修改完成后运行保留的完整测试集。
